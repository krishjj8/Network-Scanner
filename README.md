Network Scanner using Scapy

This is a simple Python script that helps you find devices connected to your local network by scanning their IP and MAC addresses. It's built using the scapy library to send ARP requests and collect responses.
Example Output:
Available devices in the network:
IP                MAC
192.168.56.1      00:11:22:33:44:55
192.168.56.2      66:77:88:99:AA:BB
